# Model setup

Download the small offline Vosk model archives you want to use and place them in this folder.

Official model list:

- https://alphacephei.com/vosk/models

Supported archives for this app:

- `vosk-model-small-en-us-0.15.tar.gz`
- `vosk-model-small-hi-0.22.tar.gz`
- `vosk-model-small-de-0.15.tar.gz`
- `vosk-model-small-fr-0.22.tar.gz`
- `vosk-model-small-cn-0.22.tar.gz`

If you only have `.zip` downloads, re-pack each extracted model folder as `.tar.gz` with the same filename used above so `vosk-browser` can load it.
